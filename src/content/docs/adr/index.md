Décision d'architecture **irréversible** ou coûteuse à changer : contexte, alternatives
envisagées, conséquences. Numérotées, immuables.

Les entrées sont listées dans la sidebar (groupe *Coulisses → Décisions*). Pour le guide
linéaire, voir aussi l'[annexe B](/grimoire-arch/guide/annexe-b-adr/).
